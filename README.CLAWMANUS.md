# 🦞 ClawManus

> OpenClaw + OpenManus 深度融合定制版

## 简介

ClawManus 是基于 OpenClaw 的定制版本，集成了 OpenManus 的核心能力。

## 功能特性

### 任务执行引擎
- 智能任务拆解
- 23+ 工具自动调用
- 进度实时追踪
- 验证 + 重试机制

### 浏览器自动化
- 智能元素定位
- 自动填表
- 动作序列执行

### 代码沙箱
- Python 沙箱
- JavaScript 沙箱
- 资源限制

### 记忆系统
- Clawlist 任务跟踪
- 长期记忆
- 语义搜索

## 版本

- **基础版本**: OpenClaw 2.17
- **定制版本**: ClawManus 1.0.0

## 安装

```bash
# 克隆
git clone https://github.com/chunxiaoxx/clawmanus.git
cd clawmanus

# 安装依赖
npm install

# 构建
npm run build

# 启动
npm start
```
